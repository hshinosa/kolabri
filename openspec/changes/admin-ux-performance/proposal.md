## Why

Admin pages saat ini sudah berfungsi dengan baik, tetapi UX dan performanya bisa ditingkatkan untuk pengalaman yang lebih baik dan lebih cepat.

## What Changes

### UX Improvements
- **Breadcrumb** di semua halaman admin
- **Global search** untuk users, courses, settings
- **Notification center** dengan history
- **Dark mode** toggle
- **Keyboard shortcuts** untuk power users

### Performance Optimizations
- **Pagination** dan **infinite scroll** untuk data loading
- **Skeleton loading** saat data loading
- **Lazy loading** untuk images
- **React Query** untuk data caching
