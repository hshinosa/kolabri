## ADDED Requirements

### Requirement: Keyboard shortcuts untuk power users
Sistem SHALL menyediakan keyboard shortcuts untuk power users.

#### Scenario: Ctrl+K untuk search
- **WHEN** admin menekan Ctrl+K
- **THEN** search bar terbuka
- **AND** admin bisa langsung mengetik untuk search

#### Scenario: Ctrl+N untuk new
- **WHEN** admin menekan Ctrl+N
- **THEN** form untuk membuat item baru terbuka
- **AND** admin bisa langsung mengisi form

#### Scenario: Escape untuk close
- **WHEN** admin menekan Escape
- **THEN** modal atau dropdown yang terbuka akan tertutup
- **AND** focus kembali ke halaman utama

#### Scenario: Shortcuts help
- **WHEN** admin menekan Ctrl+?
- **THEN** dialog shortcuts help muncul
- **AND** dialog menampilkan daftar semua shortcuts
