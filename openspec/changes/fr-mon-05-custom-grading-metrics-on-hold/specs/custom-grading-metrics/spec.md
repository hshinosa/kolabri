## ADDED Requirements

### Requirement: The platform shall support course-specific discussion monitoring metrics and rubric dimensions
The system SHALL be capable of defining course-specific monitoring dimensions and scoring them from available discussion and collaboration signals when the feature is implemented.

#### Scenario: Lecturer configures course metric dimensions
- **WHEN** the feature is activated in a future implementation phase
- **THEN** a lecturer can define or select supported discussion monitoring dimensions for that course

### Requirement: The feature remains on hold until metric taxonomy is approved
The system SHALL treat this capability as design-defined but implementation-on-hold until stakeholders approve the supported metric taxonomy and scoring model.

#### Scenario: Change remains non-implementable by default
- **WHEN** teams review this change for execution
- **THEN** the change is marked as on hold pending metric taxonomy and scope approval
