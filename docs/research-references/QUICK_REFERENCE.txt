8 METHODS ANALYZED
================================================================================

1. LayoutLMv3 (Microsoft, 2022)
   Type: Multimodal Transformer
   Key: Unified masking (MLM + MIM + WPA), not sequential
   ⚠️  NOT "OCR + layout encoder" - it's joint fusion

2. PaddleOCR v6 (Baidu, 2026)
   Type: Pure OCR Pipeline
   Key: Text detection → recognition only
   ⚠️  NOT a document parser - handles text extraction only

3. Donut (Naver CLOVA, 2021)
   Type: End-to-end VDU
   Key: OCR-free, structured output (JSON/HTML)
   ⚠️  NOT "OCR replacement" - it's visual document understanding

4. MinerU v3.4.0 (OpenDataLab, June 2026)
   Type: Multi-module Pipeline
   Key: Layout detection → task-specific recognizers (OCR, formula, table)
   ⚠️  NOT monolithic - orchestrated multi-model pipeline

5. Docling (IBM, 2026)
   Type: Configurable Pipeline
   Key: Swappable stages (layout, OCR engine, VLM)
   ⚠️  NOT fixed tool - each stage is pluggable

6. Surya v2.0 (Datalab, May 27, 2026) ⚠️ BREAKING CHANGE
   Type: Unified VLM
   Key: Single 650M model for OCR + layout + tables (was multi-model v1)
   ⚠️  v1 and v2 are ARCHITECTURALLY DIFFERENT

7. Dots MOCR (RedNote HiLab, 2026)
   Type: Document Paradigm
   Key: Text + graphics (SVG output) as first-class targets
   ⚠️  NOT traditional OCR - graphics-to-SVG is core innovation

8. MultiDocFusion (2026)
   Type: RAG Chunker
   Key: DP → OCR → LLM hierarchical parsing → chunk assembly
   ⚠️  NOT standalone parser - designed for retrieval optimization

WHAT EACH METHOD ACTUALLY DOES vs DOESN'T
================================================================================

LayoutLMv3:
  ✅ Text + layout + visual features (joint)
  ❌ Standalone OCR; scanned PDFs without preprocessing

PaddleOCR:
  ✅ Text detection + recognition
  ❌ Layout; tables; structure; graphics

Donut:
  ✅ Structured output from document images
  ❌ Raw text extraction; layout analysis; scanned PDFs

MinerU:
  ✅ Layout + text + formulas + tables + scanned PDFs
  ❌ Real-time inference; tiny device deployment

Docling:
  ✅ Pluggable stages (layout, OCR, VLM)
  ❌ Specific domain tasks without configuration

Surya v2:
  ✅ OCR + layout + tables (single 650M model)
  ❌ Formulas; complex graphics; scanned handwriting

Dots MOCR:
  ✅ Text + graphics (SVG output)
  ❌ Traditional OCR-only use cases

MultiDocFusion:
  ✅ Document hierarchy + RAG chunking
  ❌ Standalone parsing; real-time inference
